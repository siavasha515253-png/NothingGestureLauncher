# Nothing Gesture Launcher

Gesture-first Android launcher inspired by Nothing OS.

**No app drawer. Everything through gestures.**

## Gestures
- Swipe up: App search
- Swipe left/right: Pages
- Long press: Edit mode
- Pinch: Settings
- Double tap: Configurable

## Build APK
Actions tab → Build APK workflow → Download artifact

## Install
Install APK → Home button → Choose Nothing Gesture → Always
